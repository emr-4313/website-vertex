Docs/Scripting

Scripts

Find game scripts and read their environments, closures and bytecode.

getscripts

getscripts() -> {BaseScript | ModuleScript}

Returns every script and module the client knows about.

getrunningscripts

getrunningscripts() -> {LuaSourceContainer}

Returns scripts that currently have a running thread.

getloadedmodules

getloadedmodules() -> {ModuleScript}

Returns ModuleScripts that have been required.

getmodules

getmodules() -> {ModuleScript}

Returns every ModuleScript, required or not.

getcallingscript

getcallingscript() -> LuaSourceContainer?

Returns the script that called the current function. Useful inside hooks.

getscriptfromthread

getscriptfromthread(thread: thread) -> LuaSourceContainer?

Returns the script a thread belongs to.

getscriptthread

getscriptthread(script: LuaSourceContainer) -> thread?

Returns the main thread of a running script.

getsenv

getsenv(script: LocalScript | ModuleScript) -> table?

Returns a running script's global environment.

Example
local env = getsenv(game.Players.LocalPlayer.PlayerScripts.Main)
print(env.someFunction)

getmenv

getmenv(module: ModuleScript) -> table?

Returns a required module's environment.

getscriptclosure

getscriptclosure(script: LuaSourceContainer) -> function

Returns a new closure built from the script's bytecode, with its environment. Calling it runs the script again.

Aliasesgetscriptfunction

getscriptbytecode

getscriptbytecode(script: LuaSourceContainer) -> string

Returns the script's Luau bytecode.

Aliasesdumpstring

getscripthash

getscripthash(script: LuaSourceContainer) -> string?

Returns a hash of the script's bytecode. It changes whenever the script's source changes, so it is useful for detecting updates.

getfunctionbytecode

getfunctionbytecode(func: function) -> string

Serialises a single Luau function (and its nested functions) into standard Luau bytecode.

getinstancesbyclass

getinstancesbyclass(className: string) -> {Instance}

Returns cached instances whose ClassName matches.
